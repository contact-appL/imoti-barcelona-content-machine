# Имоти в Барселона — Content Machine

V1 foundation for a private content-management workspace for the “Имоти в Барселона” business.

## V1 scope
- Dashboard
- Workspace / brand profile
- Inbox
- My Ideas
- Approved Topics
- Create Post
- Calendar
- Archive
- Settings
- Integrations placeholder
- Authentication/data architecture prepared for Supabase
- Status model: Draft, Ready, Scheduled, Published, Error

## Architecture
- GitHub: source code and GitHub Actions
- GitHub Pages: frontend hosting (to be configured)
- Supabase: authentication, database, RLS and storage (to be connected)
- Meta: Facebook/Instagram publishing (to be connected and verified)

## Important
V1 does not claim that Supabase or Meta publishing is connected yet. Integrations will be marked active only after credentials, permissions and real API capabilities are verified.
